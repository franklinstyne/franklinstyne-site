My signature approach

Learn it. Apply it. Present it.

Every programme follows the same four steps, so participants leave the room having already used AI on their own work.

  1. Bring a work challenge

    Teams start with a real task from their own job: a report, a dataset, a presentation or a slow process.

  2. Learn the method

    A structured prompting framework and the right tool for the task, practised hands-on from the first hour.

  3. Build a solution

    Groups apply AI to their challenge and build a working output, with coaching as they go.

  4. Demonstrate the result

    Each group presents what they built and the time it saves, so the organisation sees the result before the day ends.
